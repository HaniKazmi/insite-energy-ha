# Pinned deliberately. Official test package replacing the retired
# pytest-homeassistant-custom-component as of HA 2026.11; it pulls in the

# silently tests a different HA — and a release can break the build with no
# change of ours. Requires Python >= 3.14.
#
# The `latest` job in tests.yml installs this unpinned on a schedule, so
# upstream breakage still surfaces — on our timetable rather than mid-PR.
